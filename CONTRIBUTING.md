# Contributing

We welcome contributions to this project! If you have an idea for a new package, have found a bug, or want to improve the documentation, please follow these steps:

1. Fork the repository and create a new branch for your package or bug fix.
2. Make your changes and commit them with clear and descriptive messages.
3. Push your changes to your forked repository.
4. Open a pull request to the main repository, describing your changes and why they are necessary

## Contributing a new package

The main documentation for adding a new package to the Scientific Computing space repositories is found here: https://spack.readthedocs.io/en/latest/packaging_guide_creation.html#creating-and-editing-packages

Once you have created a new package please have a look at the existing packages in this repository to see if there are any similar ones that you can use as a template for your new package.
